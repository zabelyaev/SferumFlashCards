## 📱 Инструкция по использованию мини-приложения

Мини-приложение создано для эффективного запоминания учебного материала (формулы, термины, иностранные слова, правила) с использованием научно обоснованного алгоритма интервальных повторений.

### 1. Вход и запуск
* Откройте бота в мессенджере MAX по ссылке: [https://max.ru/id222509298504_bot](https://max.ru/id222509298504_bot) и нажмите кнопку запуска приложения (или перейдите напрямую по веб-ссылке [https://max-bot-memory.web.app](https://max-bot-memory.web.app)).
* Авторизация происходит бесшовно через платформу MAX.

### 2. Главный экран («Главная»)
* **Статистика дня**: отображается количество карточек, готовых к повторению на сегодня, и прогресс выполнения дневного плана.
* **Ударный режим (Streak)**: счётчик дней непрерывных занятий, мотивирующий учиться регулярно.
* **Быстрый старт**: кнопка для перехода к тренировке по всем активным колодам.

### 3. Режим тренировки (Сессия повторения)
1. На экране появляется лицевая сторона карточки (вопрос, термин или задача).
2. Нажмите **«Показать ответ»** (или кликните по карточке), чтобы перевернуть её и проверить себя.
3. Оцените, насколько легко удалось вспомнить материал, выбрав одну из 4 кнопок:
   * **«Снова»** — не вспомнил (карточка вернётся в текущую сессию через несколько шагов).
   * **«Трудно»** — вспомнил с большим усилием (интервал повторения увеличится незначительно).
   * **«Хорошо»** — правильный уверенный ответ (стандартный расчёт следующего интервала).
   * **«Легко»** — ответ был очевиден (интервал повторения вырастет существенно).
4. Алгоритм автоматически рассчитывает дату следующего показа для каждой карточки индивидуально.

### 4. Каталог колод («Каталог»)
* Вкладка с готовыми наборами карточек, сгруппированными по предметам (Математика, Физика, Информатика, Химия, Английский язык и др.).
* Любую понравившуюся колоду можно добавить в свою библиотеку в один клик.

### 5. Создание и редактирование своих карточек («Библиотека»)
* Нажмите кнопку **«Создать колоду»**, укажите название, предмет и цвет обложки.
* Внутри колоды добавляйте карточки с вопросом, ответом и подсказкой.
* **Поддержка формул LaTeX**: формулы, заключенные в знаки доллара (например, `$E = mc^2$` или `$\frac{-b \pm \sqrt{D}}{2a}$`), автоматически преобразуются в красивый математический вид благодаря встроенному движку KaTeX.

### 6. Обмен колодами («Поделиться»)
* Вы можете поделиться созданной колодой с одноклассниками, учениками или друзьями по сгенерированной ссылке или QR-коду.

## 🚀 Быстрый запуск через Docker Compose

Для локального запуска требуется установленный **Docker** (версии 24+) и плагин **Docker Compose**.

### Шаг 1. Клонирование репозитория

```bash
git clone https://github.com/Dracovolodeus/memory-all.git
cd memory-all
```

### Шаг 2. Подготовка переменных окружения

В корне проекта скопируйте файл с переменными окружения:

```bash
cp .env.example .env
```

> **Примечание**: Параметр `APP_CONFIG__AUTH__APP_KEY` используется для авторизации запросов фронтенда к бэкенду. В `.env.example` задано рабочее значение по умолчанию: `zapominalka-secret-key`.

### Шаг 3. Сборка и запуск контейнеров

```bash
docker compose up -d --build
```

**Что происходит автоматически при запуске:**
1. Запускается контейнер с СУБД **PostgreSQL 18** и инициализируются роли пользователей (`init-roles.sh`).
2. Сервис `migrate` дожидается готовности БД и автоматически накатывает актуальные миграции **Alembic**.
3. Запускается сервис **FastAPI Backend** на порту `8000`.
4. Запускается фоновый планировщик оптимизации интервалов **FSRS Optimizer**.
5. Собирается и запускается сервис **Frontend (Nginx)** на порту `5173`.

### Шаг 4. Проверка статуса сервисов

```bash
docker compose ps
```

Все контейнеры должны иметь статус `running` (`Up`), а сервис `migrate` — `exited (0)`.

### Шаг 5. Доступ к приложению

* 📱 **Веб-интерфейс приложения**: [http://localhost:5173](http://localhost:5173)
* 🔌 **Backend REST API**: [http://localhost:8000](http://localhost:8000)
* 📖 **Интерактивная документация API (Swagger UI)**: [http://localhost:8000/internal/docs](http://localhost:8000/internal/docs)
  * *Логин*: `admin`
  * *Пароль*: `admin`

### Просмотр логов и остановка

```bash
# Просмотр логов в реальном времени:
docker compose logs -f

# Логи конкретного сервиса (например, бэкенда):
docker compose logs -f app

# Остановка контейнеров:
docker compose down
```

# ApiForHack

## Запуск
Нужен Docker с Docker Compose. Проверено на Docker 29.2.2.

1. В корне проекта создайте `.env`:

   ```bash
   echo "" > .env
   ```

2. Задайте в `.env` собственный непустой `APP_CONFIG__AUTH__APP_KEY`. Этот же
   ключ должен использовать frontend. Для реальной эксплуатации также замените пароли БД
   по умолчанию, для тестовых запусков можно оставить все параметры, за исключением `APP_CONFIG__AUTH__APP_KEY`, со значениями по умолчанию.

3. Соберите и запустите сервисы:

   ```bash
   docker compose up -d --build
   ```

Миграции применяются автоматически. API доступен на `http://127.0.0.1:8000`;
документация по умолчанию выключена.

Просмотр логов и остановка:

```bash
docker compose logs -f # Просмотр логов
docker compose down    # Остановка
```
